# Software Pricing

Software now has a usage-plan foundation for commercial SaaS customers.

## Plans

| Plan | Projects | API Keys | Workflows / Month | Intended User |
| --- | ---: | ---: | ---: | --- |
| Free | 1 | 1 | 1,000 | Individual developers |
| Pro | 20 | 50 | 100,000 | Teams running production agents |
| Enterprise | Unlimited | Unlimited | Custom | Large organizations |

## Free

Free is the default plan assigned when a user registers.

Limits:

- 1 project
- 1 API key
- 1,000 workflows/month

## Pro

Pro is for teams.

Limits:

- 20 projects
- 50 API keys
- 100,000 workflows/month

## Enterprise

Enterprise is for organizations that need custom contracts and deployment options.

Limits:

- Unlimited projects
- Unlimited API keys
- Custom workflow limits

## Current Status

Billing provider integration is not connected yet. The system includes:

- plan records
- subscriptions
- usage tracking
- limit enforcement
- dashboard usage display
- upgrade placeholder

The next production step is connecting Stripe, Paddle, or another billing provider.
