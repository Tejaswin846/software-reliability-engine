Step-by-step setup

1. Install or update Matrixs

Install the current Matrixs CLI, or upgrade an existing installation.

2. Run matrixs connect

Matrixs discovers the Python project and asks for permission.

3. Choose automatic or manual

Approve Matrixs changes or open the manual guide. Nothing is changed before permission.

4. Enter credentials

The local setup page asks for Project ID and API key without putting either in the command.

5. Save and verify

Matrixs backs up the project, saves credentials locally, adds integration files, and sends a test event.

6. Run with Matrixs

Use matrixs run; no source-code paste is required.
