Step-by-step setup

        

          
1. Create project
Create or select the project that should receive workflow telemetry.

          
2. Generate API key
Generate a key here or on the API Keys page. Full keys are only shown once.

          
3. Install SDK
Use GitHub install today. Switch to PyPI after the package is published.

          
4. Run software login
Save API URL and API key in your local user config.

          
5. Run software test
Send a real test workflow through the SDK ingestion API.

          
6. View dashboard
Open the SDK Workflows panel and confirm the test workflow appears.
