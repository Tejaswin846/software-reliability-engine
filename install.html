Step-by-step setup

1. Install Matrixs

Install the Python package once.

2. Run matrixs connect

Matrixs discovers the Python project and asks for permission.

3. Authorize once

The short-lived token is exchanged automatically; no permanent API key is copied.

4. Review changes

Matrixs shows its plan and creates a reversible backup.

5. Verify connection

Matrixs sends a real test event and rolls back automatically if integration fails.

6. Run with Matrixs

Use matrixs run; no source-code paste is required.
