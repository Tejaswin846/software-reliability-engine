Capabilities

Everything needed to test real AI workflow operations

Use Matrixs locally without signing in, then connect protected cloud features only when a project needs shared state, integrations, and audit logs.

Public SDK install

Install with pip or npm, read docs, run local validation, and try sandbox workflows without an account.

Clerk authentication

Sign-up, login, password reset, email verification, Google OAuth, GitHub OAuth, sessions, and account management run through Clerk.

Safe execution gates

Risky actions dry-run by default, high-risk work requires confirmation, and unsafe database or delete operations are blocked.

Tool reliability

Track model calls, tool calls, latency, confidence, failure reasons, and recovery attempts across external AI agents.

User isolation

Projects, workflows, memory, audit logs, API keys, and settings are scoped to the Clerk user id.

Audit-ready reports

Keep durable events for successful safe actions, blocked actions, timeline entries, and final reliability scores.
