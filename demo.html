Why Software?

AI agents are moving from demos into real business workflows. Once agents call tools, make plans, retry work, and route outputs to other systems, reliability becomes the product. Software gives teams the operating layer for measuring that reliability.

Key Features

Workflow telemetry

Track every workflow, stage, completion, confidence score, and latency.

Tool reliability

Separate model failures from search, extraction, endpoint, timeout, and parsing failures.

Guardrails

Predict failure probability and recommend continue, retry, observe, or escalate actions.

Projects and API keys

Give each agent app its own project-scoped API key and dashboard data.

Usage plans

Free, Pro, and Enterprise limits are tracked with billing-ready usage records.

Developer SDK

Instrument Python agents with a few lines of code and no external APIs required.

How It Works

1. Create project

Register, create a project, and generate a hashed API key.

2. Install SDK

Install the Python SDK and add telemetry around workflows, stages, model calls, and tool calls.

3. Watch reliability

Use the dashboard to see usage, failures, predictions, and guardrail outcomes.

Quickstart

pip install software-sdk set SOFTWARE_API_URL=https://YOUR_SOFTWARE_URL set SOFTWARE_API_KEY=sw_your_key python examples/simple_agent.py

A developer should be able to create a project, generate an API key, run an example, and see a workflow in the dashboard within five minutes.
