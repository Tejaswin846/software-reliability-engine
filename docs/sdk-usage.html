SDK Usage

The Python SDK sends workflow telemetry to Software using standard HTTP requests.

Basic workflow

from software_sdk import ReliabilityMonitor

monitor = ReliabilityMonitor(
    project_name="my-agent",
    api_url="https://YOUR_SOFTWARE_URL",
    api_key="sw_..."
)

with monitor.track_workflow("research-task") as workflow:
    workflow.track_stage("search", status="completed", success=True, latency_ms=1200, confidence=0.94)
    workflow.log_tool_call("parallel_search", success=True, latency_ms=1200, result_count=5)
    workflow.log_model_call("llama3.2:3b", success=True, latency_ms=5000, confidence=0.91)
    prediction = workflow.predict_failure()
    guardrail = workflow.apply_guardrail()
    workflow.complete(success=True, confidence=0.91)

Methods

  • track_workflow(): starts a workflow context.
  • track_stage(): records stage status, latency, confidence.
  • log_tool_call(): records tool name, success, latency, result count.
  • log_model_call(): records model name, success, latency, confidence.
  • log_error(): records an error or fatal failure.
  • predict_failure(): requests failure probability.
  • apply_guardrail(): returns the recommended action.
  • complete(): marks workflow success or failure.
