Matrixs Integration

Automatic integration

pip install --upgrade git+https://github.com/Tejaswin846/software-reliability-engine.git
matrixs connect

Matrixs discovers the project and asks permission. If approved, it opens a secure page served only on your computer for the Project ID and API key. It then backs up changed paths, saves credentials in a git-ignored local file, adds the runtime integration, and verifies the connection.

Manual integration

If you decline automatic changes, install the package and set these environment variables in your own secret manager or local .env file:

MATRIXS_PROJECT_ID=prj_your_project_id
MATRIXS_API_KEY=mx_your_api_key
MATRIXS_API_URL=https://software-reliability-engine.onrender.com
MATRIXS_PROJECT_NAME=your-project

Then add the monitor where your agent workflow starts:

import os
from matrixs import ReliabilityMonitor

monitor = ReliabilityMonitor(
    project_name=os.environ["MATRIXS_PROJECT_NAME"],
    api_url=os.environ["MATRIXS_API_URL"],
    api_key=os.environ["MATRIXS_API_KEY"],
)

with monitor.track_workflow("agent-run") as workflow:
    workflow.track_stage("started")
    # Run your existing agent code here.
    workflow.complete(success=True, confidence=1.0)

monitor.flush()

Keep API keys out of source control. Create or revoke a manual key in Project Connection.

Run and verify

matrixs status
matrixs run

Automatic integration uses these commands after setup. For a fully manual integration, run the application with your normal start command and confirm its workflow in the Matrixs Reliability dashboard.
