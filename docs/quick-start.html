Quick Start

Get from a new account to a visible workflow in the dashboard in about five minutes.

1. Install the SDK

pip install software-sdk

For local development from this repository, use:

python -m pip install --upgrade pip
pip install -e .

2. Create an account

Open /register, create an account, and continue to Projects.

3. Create a project

Open /projects, create a project such as my-agent-dev.

4. Generate an API key

Open /api-keys, select your project, and create an API key. Copy the full key immediately.

5. Run an example

set SOFTWARE_API_URL=https://YOUR_SOFTWARE_URL
set SOFTWARE_API_KEY=sw_your_key
python examples/simple_agent.py

6. See the workflow

Open /dashboard. If you are logged in, the dashboard uses your project-scoped SDK workflow data.
