Quick Start

1. Install Matrixs

pip install git+https://github.com/Tejaswin846/software-reliability-engine.git

2. Generate a one-time connection command

Open Project Connection, choose a project, and generate a command that expires after 15 minutes and works once.

3. Run the generated command

matrixs connect --token mxct_... --api-url https://software-reliability-engine.onrender.com
matrixs status
matrixs run

Matrixs discovers the Python project, shows its plan, creates a reversible backup, configures monitoring, and verifies the cloud connection.

4. View results

Open /dashboard after signing in. Project-scoped SDK workflows appear in the SDK Workflows panel.
