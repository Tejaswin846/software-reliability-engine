Quick Start

1. Install Matrixs

pip install git+https://github.com/Tejaswin846/software-reliability-engine.git

2. Open Project Connection

Create a project and permanent API key at Project Connection, then keep the Project ID and API key ready for the secure local setup page.

3. Run the command

matrixs connect
matrixs status
matrixs run

Matrixs discovers the Python project, asks permission, opens the local credential page, creates a reversible backup, saves the credentials locally, configures monitoring, and verifies the cloud connection. Choose manual integration when prompted if you prefer to make the changes yourself.

4. View results

Open /dashboard after signing in. Project-scoped SDK workflows appear in the SDK Workflows panel.
