Quick Start

1. Install publicly

pip install software-sdk
npm install software-sdk

2. Try local mode

Use local validation, local plans, dry-run examples, and sandbox workflows without signing in.

3. Connect cloud when needed

software login
# or
SOFTWARE_API_KEY=sw_your_key

Sign in only when you need protected cloud execution, saved projects, user memory, audit logs, integrations, or team features.

4. View results

Open /dashboard after signing in. Project-scoped SDK workflows appear in the SDK Workflows panel.
