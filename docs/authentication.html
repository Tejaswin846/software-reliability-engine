Authentication

Software uses bcrypt for password hashing and JWT bearer tokens for authenticated dashboard and management requests.

Register

POST /auth/register
{"email":"dev@example.com","password":"strong-password"}

Login

POST /auth/login
{"email":"dev@example.com","password":"strong-password"}

Use JWT

Authorization: Bearer YOUR_JWT

Current user

GET /auth/me

JWTs expire according to SOFTWARE_JWT_EXPIRE_MINUTES.
