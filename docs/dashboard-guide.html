Dashboard Guide

The dashboard shows reliability data from benchmark runs and SDK-submitted workflows.

Overview

Shows total workflows, success rate, failure rate, reliability score, latency, and confidence.

SDK Workflows

Shows recent external-agent workflows with status, prediction risk, guardrail action, and latency.

Authenticated dashboard

If you are logged in, the dashboard requests /api/me/dashboard and displays only your project-scoped SDK workflow data.

Global dashboard

If no user is logged in, the dashboard requests /api/dashboard and displays global benchmark and SDK data.
