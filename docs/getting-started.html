Getting Started

Software helps developers measure, predict, and improve AI-agent reliability. It receives workflow telemetry from your agents through the Python SDK and turns that data into dashboard metrics.

Core Concepts

  • User: an account owner.
  • Project: a scope for one agent app, team, or environment.
  • API Key: a project-scoped key used by the SDK.
  • Workflow: one complete agent execution.
  • Stage: a step inside a workflow, such as search or generation.
  • Guardrail: a recommended intervention based on failure probability.

Typical Flow

Create account -> Create project -> Generate API key -> Install SDK -> Run agent -> View dashboard
