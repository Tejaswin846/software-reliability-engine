Project Connection

The standard Matrixs flow uses a short-lived, single-use token. It exchanges the token inside the CLI and does not display a permanent API key.

Generate command

POST /api/projects/{project_id}/connection-token

Run command

matrixs connect --token mxct_... --api-url https://software-reliability-engine.onrender.com

The command expires after 15 minutes, works once, asks permission before changes, creates a backup, and verifies the connection. Permanent API keys remain available only in the advanced project connection panel.
