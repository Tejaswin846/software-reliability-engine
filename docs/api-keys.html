Project Connection

The standard Matrixs flow uses one secret-free command for every project.

Run command

matrixs connect

Matrixs discovers the project and asks permission before any changes. If approved, it opens a secure page served only on your computer, where you enter the Project ID and API key. Matrixs then creates a backup, saves credentials to a git-ignored file, applies the integration, and verifies it.

Manual integration

Decline automatic integration in the terminal, or run matrixs connect --manual, to open the manual guide without changing files.
