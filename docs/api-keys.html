API Keys

API keys connect external agents to a Software project. The full key is shown once and only a hash is stored.

Create key

POST /api/projects/{project_id}/api-keys

List keys

GET /api/projects/{project_id}/api-keys

Lists show only key_prefix, created_at, last_used_at, and active state.

Revoke key

DELETE /api/projects/{project_id}/api-keys/{key_id}

Use key in SDK

monitor = ReliabilityMonitor(
    project_name="my-agent",
    api_url="https://YOUR_SOFTWARE_URL",
    api_key="sw_..."
)
