Troubleshooting

401 Missing bearer token

You are calling a user/project endpoint without Authorization: Bearer YOUR_JWT. Login first.

403 Invalid SDK API key

The SDK key is missing, invalid, revoked, or belongs to another project. Generate a fresh key in /api-keys.

Workflow not visible

Confirm your SDK uses the same API URL as the dashboard and that workflow.complete() ran.

Dashboard shows global data

Login first. The dashboard switches to /api/me/dashboard only when a JWT is stored in the browser.

Server health fails

Open /health and check database and dashboard asset status.

Install fails

Use Python 3.10+ and install from the project root with pip install -e . during local development.
