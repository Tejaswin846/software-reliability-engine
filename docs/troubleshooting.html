Troubleshooting

401 Missing bearer token

The endpoint is a protected cloud feature. Sign in with Clerk or send a project API key. You can still install and use the SDK locally without signing in.

403 Invalid SDK API key

The SDK key is missing, invalid, revoked, or belongs to another project. Generate a fresh key in /api-keys.

Workflow not visible

Confirm your SDK uses the same API URL as the dashboard and that workflow.complete() ran.

Server health fails

Open /health for lightweight status and /status for deep provider checks.

Install fails

Use Python 3.10+ and install from PyPI with pip install software-sdk. Local repo development can use pip install -e ..
