Installation

Install without login

pip install software-sdk
npm install software-sdk

The SDK install, docs, local validation, local planning, dry-run examples, and sandbox workflows are public.

Optional cloud login

software login
# or
SOFTWARE_API_KEY=sw_your_key

Cloud workflow execution, saved projects, user memory, audit logs, external app integrations, and team features require Clerk login or an API key.

Develop from this repository

python -m pip install --upgrade pip
pip install -e .

Run the server locally

pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8300
