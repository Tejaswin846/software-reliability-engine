Installation

Install Matrixs

pip install --upgrade git+https://github.com/Tejaswin846/software-reliability-engine.git

The package includes the matrixs connector and the reliability runtime.

Connect with a secret-free command

matrixs connect

Matrixs asks permission, then opens a loopback-only page for your Project ID and API key. It stores the credentials in a git-ignored local file, applies the integration, and verifies the connection. Decline automatic integration to use the manual guide.

Develop from this repository

python -m pip install --upgrade pip
pip install -e .

Run the server locally

pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8300
