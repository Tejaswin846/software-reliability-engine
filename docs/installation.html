Installation

Install the SDK

pip install software-sdk

When developing from this repository:

python -m pip install --upgrade pip
pip install -e .

Run the server locally

pip install -r requirements.txt
uvicorn Software.app:app --host 127.0.0.1 --port 8300

Required server environment

SOFTWARE_JWT_SECRET=replace-with-a-long-random-secret
SOFTWARE_ENABLE_BOOTSTRAP_DEV_KEY=false
SOFTWARE_API_DB_PATH=Software/data/software_reliability.db

Check health

curl http://127.0.0.1:8300/health
