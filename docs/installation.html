Installation

Install Matrixs

pip install git+https://github.com/Tejaswin846/software-reliability-engine.git

The package includes the matrixs connector and the reliability runtime.

Connect without copying an API key

matrixs connect --token mxct_... --api-url https://software-reliability-engine.onrender.com

Generate this single-use command from Project Connection. Matrixs stores the exchanged credential locally and never displays it in the standard flow.

Develop from this repository

python -m pip install --upgrade pip
pip install -e .

Run the server locally

pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8300
