Guardrails Guide

Guardrails are recommendations based on the workflow events already submitted by the SDK.

Prediction

prediction = workflow.predict_failure()

Prediction returns probability_of_failure, probability_of_success, and a recommended guardrail.

Apply guardrail

guardrail = workflow.apply_guardrail()

Actions

  • continue: risk is acceptable.
  • increase_observation: continue with tighter monitoring.
  • retry_failed_stage: retry before moving on.
  • escalate: stop automated execution and involve a human.

What increases risk?

Failed tool calls, failed model calls, logged errors, long latency, and low confidence all raise predicted failure probability.
