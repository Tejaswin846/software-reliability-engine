Zero-code integration

Connect a project with one command.

Run the same safe command beside any Python project. Matrixs discovers the application, asks permission, opens a secure local page for your Project ID and API key, then applies and verifies the integration.

Run this in your terminal

There are no IDs, API keys, or temporary tokens in this command.

matrixs connect

Your API key is entered later on a page served only by the Matrixs CLI on your computer. It never appears in shell history or in the page URL.

What happens after you run it

1

Discover

Matrixs finds supported Python projects and lets you choose the correct one.

2

Ask permission

Nothing changes until you explicitly allow automatic integration.

3

Enter credentials

A private local page asks for your Project ID and API key.

4

Apply & verify

Matrixs backs up the project, saves credentials locally, adds the integration files, and sends a test event.
