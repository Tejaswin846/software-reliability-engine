Setup Checklist

Step 1: Create project

Create a project in Software so your agent telemetry has a workspace.

Open Projects

Step 2: Generate API key

Create a project API key. The full key is shown once, so keep it somewhere safe.

Open API Keys

Step 3: Install SDK

Install the Python package in your agent project.

pip install software-sdk

Step 4: Run software login

Save your API URL and API key locally.

software login

Step 5: Run software test

Send a test workflow to prove the SDK, API key, and dashboard are connected.

software init software test

Step 6: View dashboard

Open the dashboard and check the SDK workflows panel for your test event.

Open Dashboard

Minimal Agent Example

from software_sdk import ReliabilityMonitor monitor = ReliabilityMonitor( project_name="my-agent", api_url="https://software-platform.onrender.com", api_key="sw_..." ) with monitor.track_workflow("research-task") as workflow: workflow.track_stage("search", status="completed", success=True, latency_ms=1200, confidence=0.94) workflow.log_tool_call("parallel_search", success=True, latency_ms=1200, result_count=5) workflow.log_model_call("llama3.2:3b", success=True, latency_ms=5000, confidence=0.91) workflow.complete(success=True, confidence=0.91)
