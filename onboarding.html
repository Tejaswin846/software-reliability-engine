Setup Checklist

Step 1: Choose a Matrixs project

Create or select the cloud project that will own the reliability records.

Open Projects

Step 2: Copy the command

Copy matrixs connect. It contains no token, Project ID, or API key.

Open Project Connection

Step 3: Run beside your project

Install Matrixs, then run matrixs connect from the folder containing your project.

pip install git+https://github.com/Tejaswin846/software-reliability-engine.git

Step 4: Choose automatic or manual

Matrixs asks permission before any change. Decline to open the manual integration guide.

Step 5: Automatic verification

The CLI opens a private local credential page, then creates a reversible backup, configures Matrixs, and sends a real verification event.

Step 6: Run normally

Start with matrixs run and inspect the verification workflow in Reliability.
